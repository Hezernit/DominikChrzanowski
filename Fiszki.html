English Flashcards

A lightweight browser app for studying English vocabulary with flip cards and a built-in word editor.

Open live demo Download source Back to homepage

Project overview

English Flashcards is a static web application built with plain HTML, CSS and JavaScript. It helps with vocabulary practice by showing one word at a time, flipping the card to reveal the translation and storing custom words in the browser.

The project focuses on practical frontend logic: state management without a framework, dynamic rendering, responsive card layout and persistent data with localStorage.

Key features

Flip cards Random word Previous and next Add cards Edit cards Delete cards localStorage

How to use it

  1. Open the live demo using the button above.
  2. Use the study view to flip cards, move between words or pick a random card.
  3. Open the word editor to add, edit or delete your own flashcards.
  4. Your changes are saved in the browser with localStorage.

Tech stack

The app uses standalone HTML, CSS and JavaScript, so it does not require a build step or backend server. It can run directly from the browser.
