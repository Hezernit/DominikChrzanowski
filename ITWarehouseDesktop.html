IT Warehouse Desktop

A desktop inventory system for tracking IT assets, assignments, statuses and change history.

Download app Back to homepage

Project overview

IT Warehouse Desktop is a Windows desktop application built with C# and WinForms on .NET. It uses a local SQLite database to manage hardware inventory records, users, permissions and audit logs.

The app focuses on everyday warehouse work: quick asset lookup, issuing and returning devices, service status, reservations, archiving records and keeping a clear history of changes.

Key features

Login and roles Asset database Quick scan/search Audit history CSV import/export Database backup SQLite storage

How to run the app

  1. Download the ZIP file using the button above.
  2. Extract the whole ZIP archive to any folder on your Windows computer.
  3. Open the extracted folder and run ITWarehouseDesktop.exe.
  4. If Windows shows a SmartScreen warning, choose More info and then Run anyway.

Keep all extracted files together, including the SQLite database and DLL files, because the application needs them to start correctly.

Tech stack

The project is written in C# using Windows Forms, targets .NET for Windows, and stores data with Microsoft.Data.Sqlite. It includes separate application models, database handling and login/main form flows.
