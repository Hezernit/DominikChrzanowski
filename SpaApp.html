Event Manager SPA

A single-page application for listing events, opening event details and adding new event records.

Download source Back to homepage

Project overview

Event Manager SPA is a university project built as a React application with Vite and React Router. It communicates with a local API, loads events from JSON data, displays event details and includes a form for adding new events.

The project shows a clean frontend flow: routing, API service separation, form validation and basic CRUD-style interaction with a local JSON backend.

Key features

React components Client-side routing Event list Event details Add event form Axios API service JSON data

How to run the app

  1. Download and extract the source ZIP.
  2. Open a terminal in the extracted project folder.
  3. Run npm install to install dependencies.
  4. Start the JSON API on port 3001 using npx json-server --watch db.json --port 3001.
  5. In a second terminal, run npm run dev and open the local Vite address in your browser.

The frontend expects the API at http://localhost:3001, so the JSON server should keep running while you test the app.

Tech stack

The project uses React, Vite, React Router and Axios. Local test data is stored in db.json and served through a JSON API during development.
